Pipeline de consolidación de datos

Dos sistemas registran las mismas solicitudes con nombres escritos distinto. El pipeline los cruza, normaliza los nombres con distancia de edición, clasifica el estado de cada registro y deja el resultado trazable: se puede repetir la corrida y obtener lo mismo.
