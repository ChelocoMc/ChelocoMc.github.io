Medida del modelo

Cumplimiento % =
VAR Ejecutadas  = CALCULATE( COUNTROWS( Mantenciones ), Mantenciones[Estado] = "Ejecutada" )
VAR Programadas = COUNTROWS( Mantenciones )
RETURN DIVIDE( Ejecutadas, Programadas )

La regla que costó encontrar: una columna calculada referenciaba a otra creada en el mismo bloque de agregación, algo que DAX no permite aunque no lo marque como error evidente. Se resolvió recalculando con variables, como arriba. Y del lado de la carga, un error sin línea ni columna ("se esperaba el token Literal") resultó ser un operador de coalescencia que ese motor de M no soporta — se aisló instalando el parser oficial del lenguaje.

Esto es la idea funcionando con datos inventados. Lo tuyo se construye desde cero, con tus fuentes y tus reglas: cuéntame el proceso y en 48 horas te digo si conviene automatizarlo y cuánto vale.
